The paper in 60 seconds

  • 150 marks in 3 hours. That is about 1.2 minutes per mark. Aim to finish with 10 minutes to check.
  • Mark split (DBE exam guidelines): Functions 35, Calculus 35, Algebra 25, Patterns 25, Finance 15, Probability 15.
  • Difficulty split: about 30 marks Knowledge, 52 Routine, 45 Complex, 22 Problem Solving. So roughly 82 marks (55%) are knowledge and routine procedures. Bank those first.
  • Cheapest marks to revise tonight: Finance and Probability (30 marks, very predictable) and the first parts of every question.
  • Not examined (per the guidelines): solving quadratics by completing the square, conditional probability, combinations (nCr), circular arrangements, solving for i in annuity formulae, pyramid schemes, recursive patterns.

Method marks, every question

  • Write the formula, then substitute. A wrong final answer can still earn method marks.
  • Keep full calculator values until the last line. Round to 2 decimals only at the end.
  • “Show that…” gives you the answer. Use it in the next part even if you could not prove it.
  • Do not cross out work unless you have replaced it.
  • Label sketches: intercepts, turning points, asymptotes (dashed).
  • Answer in words when the question is a context problem, with units.

Algebra, Equations and Inequalities

Usually Question 1
25 marks

Must know

  • Quadratic formula: x = (−b ± √(b² − 4ac)) / 2a
  • Exponents: aᵐ·aⁿ = aᵐ⁺ⁿ aᵐ ÷ aⁿ = aᵐ⁻ⁿ (aᵐ)ⁿ = aᵐⁿ a⁻ⁿ = 1/aⁿ a^(m/n) = ⁿ√(aᵐ) a⁰ = 1
  • Logs: logab = c ⇔ aᶜ = b (b > 0) · log(xy) = log x + log y · log(x/y) = log x − log y · log xⁿ = n·log x · logaa = 1 · loga1 = 0
  • Discriminant Δ = b² − 4ac. Δ > 0: two real unequal roots (rational if Δ is a perfect square). Δ = 0: two equal real roots. Δ < 0: no real roots.
  • Calculator: solve aˣ = b with x = log b / log a.
TYPE 1

Solve a quadratic equation

“Solve for x: 2x² − 3x = 4” · “Solve for x, correct to TWO decimal places.”

  1. Move everything to one side: ax² + bx + c = 0.
  2. Factorise if it factorises quickly. If the question says “correct to two decimals”, use the formula.
  3. Write the formula with the substitution, then both answers.
Worked example

Solve 2x² − 3x − 4 = 0, correct to 2 decimals.

x = (3 ± √(9 + 32)) / 4 = (3 ± √41) / 4 x = 2,35 or x = −0,85
TYPE 2

Quadratic in disguise (the k-substitution)

“Solve for x: 3²ˣ − 4·3ˣ + 3 = 0” · “x⁴ − 5x² + 4 = 0” · “x − 5√x + 4 = 0”

  1. Spot the repeated block (3ˣ, x², √x). Let it equal k.
  2. Solve the quadratic in k.
  3. Go back: replace k, solve for x.
  4. Reject impossible values (aˣ is never negative, √x is never negative).
Worked example

Solve 2²ˣ − 3·2ˣ − 4 = 0.

Let k = 2ˣ: k² − 3k − 4 = 0 (k − 4)(k + 1) = 0 → k = 4 or k = −1 2ˣ = 4 → x = 2 2ˣ = −1 → no solution (2ˣ > 0) x = 2
TYPE 3

Equations with fractions

“Solve for x: 3/(x − 1) + 2/(x + 1) = 1”

  1. State the restrictions first (denominators ≠ 0).
  2. Multiply every term by the common denominator.
  3. Expand, collect, solve the quadratic.
Worked example

Solve 3/(x − 1) + 2/(x + 1) = 1, x ≠ ±1.

3(x + 1) + 2(x − 1) = (x − 1)(x + 1) 5x + 1 = x² − 1 x² − 5x − 2 = 0 x = (5 ± √33) / 2 x = 5,37 or x = −0,37
TYPE 4

Equations with surds (square, then CHECK)

“Solve for x: x − 1 = √(x + 5)”

  1. Isolate the root on one side.
  2. Square both sides (square the whole side, not each term).
  3. Solve the quadratic.
  4. Substitute both answers back. Squaring creates fake solutions. This check is worth a mark.
Worked example

Solve x − 1 = √(x + 5).

(x − 1)² = x + 5 x² − 3x − 4 = 0 → (x − 4)(x + 1) = 0 x = 4: LHS = 3, RHS = √9 = 3 ✓ x = −1: LHS = −2, RHS = √4 = 2 ✗ x = 4 only
TYPE 5

Exponential equations

“Solve for x: 2ˣ⁺³ − 2ˣ = 56” · “Solve for x: 5ˣ = 20 (2 decimals)”

  1. Same base possible? Make bases equal, then equate exponents.
  2. Sum or difference of powers: factor out the smallest power (2ˣ⁺³ = 2ˣ·2³).
  3. Cannot make bases equal? Use logs: x = log b / log a.
Worked example

Solve 2ˣ⁺³ − 2ˣ = 56.

2ˣ(2³ − 1) = 56 → 7·2ˣ = 56 → 2ˣ = 8 x = 3

Solve 5ˣ = 20.

x = log 20 / log 5 = 1,86
TYPE 6

Logarithm equations and log form

“Solve for x: log₂x + log₂(x − 2) = 3” · “Solve: log₃(x − 1) = 2” · “Write x in terms of y: y = log₅x”

  1. Combine logs with the laws until you have a single log on each side.
  2. Convert to exponential form: logab = c ⇒ b = aᶜ.
  3. Solve, then reject any x that makes a log argument ≤ 0.
Worked example

Solve log₂x + log₂(x − 2) = 3.

log₂[x(x − 2)] = 3 → x(x − 2) = 2³ = 8 x² − 2x − 8 = 0 → (x − 4)(x + 2) = 0 x = −2 rejected (log of a negative) x = 4
TYPE 7

Simultaneous equations (linear + quadratic)

“Solve for x and y: y = x − 1 and x² + y² = 25” · Also hides inside: “Find the points of intersection of the line and the curve.”

  1. Make one variable the subject of the linear equation.
  2. Substitute into the quadratic. Brackets! (x − 1)² = x² − 2x + 1.
  3. Solve, then find the matching y for each x using the linear equation.
  4. Present answers as pairs.
Worked example
x² + (x − 1)² = 25 2x² − 2x − 24 = 0 → x² − x − 12 = 0 (x − 4)(x + 3) = 0 x = 4, y = 3 or x = −3, y = −4 Check (4; 3): 16 + 9 = 25 ✓
TYPE 8

Inequalities (quadratic and fractional)

“Solve for x: x² − 2x − 3 < 0” · “Solve for x: x/(x − 3) ≤ 2”

  1. Get 0 on one side. Never multiply or divide by an expression with x.
  2. Fraction? Combine into a single fraction.
  3. Find critical values (numerator = 0 and denominator = 0).
  4. Sketch the parabola, or draw a sign table. Pick the region(s) that match < or >.
  5. Denominator zero is always excluded.
Worked example

Solve x² − 2x − 3 < 0.

(x − 3)(x + 1) < 0 (parabola below the x-axis) −1 < x < 3

Solve x/(x − 3) ≤ 2.

x/(x − 3) − 2 ≤ 0 → (6 − x)/(x − 3) ≤ 0 Critical values: x = 3 (excluded) and x = 6 x < 3: neg ✓ · 3 < x < 6: pos ✗ · x > 6: neg ✓ x < 3 or x ≥ 6
TYPE 9

Nature of the roots

“For which values of k will x² − 4x + k = 0 have real roots?” · “Prove that the roots of x² + kx − 1 = 0 are real for all k.” · “Determine the value of k for which the roots are equal.”

  1. Write down a, b, c (k can be one of them) and Δ = b² − 4ac.
  2. Real roots: Δ ≥ 0. Equal roots: Δ = 0. Non-real: Δ < 0. Rational: Δ a perfect square.
  3. “Prove for all k”: show Δ is a square plus a positive number, or always positive.
Worked example
x² − 4x + k = 0: Δ = 16 − 4k ≥ 0 → k ≤ 4 x² + kx − 1 = 0: Δ = k² + 4 k² ≥ 0, so Δ ≥ 4 > 0 for every k: roots always real and unequal.
TYPE 10

Make a letter the subject of a formula

“Make a the subject of x = (a + b)/(a − b).”

  1. Clear fractions.
  2. Expand. Gather every term containing the required letter on one side.
  3. Factorise out that letter and divide.
Worked example
x(a − b) = a + b xa − xb = a + b xa − a = b + xb a(x − 1) = b(1 + x) a = b(x + 1) / (x − 1)
TYPE 11

Simplify or prove with exponents and surds

“Simplify without a calculator: (2ⁿ⁺² − 2ⁿ) / (3·2ⁿ)” · “Show that 1/(√5 − √3) = (√5 + √3)/2”

  1. Break each power into a common base: 2ⁿ⁺² = 2ⁿ·2².
  2. Factor out the common power and cancel.
  3. Rationalise a denominator by multiplying top and bottom by the conjugate (√5 + √3). The product gives 5 − 3.
Worked example
(2ⁿ·4 − 2ⁿ) / (3·2ⁿ) = 2ⁿ(4 − 1) / (3·2ⁿ) = 1 1/(√5 − √3) × (√5 + √3)/(√5 + √3) = (√5 + √3)/(5 − 3) = (√5 + √3)/2 ✓

Traps in this topic

  • Dividing both sides by x. You lose the solution x = 0. Factorise instead.
  • Forgetting the ± or the second solution.
  • Not checking surd and log answers.
  • Multiplying an inequality by a negative without flipping the sign (or by an x-expression at all).
  • Squaring a sum term by term: (x − 1)² is x² − 2x + 1, never x² − 1.

Number Patterns, Sequences and Series

Usually Questions 2 and 3
25 marks

Must know

  • Arithmetic (constant difference d): Tₙ = a + (n − 1)d · Sₙ = n/2 [2a + (n − 1)d] · Sₙ = n/2 (a + l)
  • Geometric (constant ratio r): Tₙ = a·rⁿ⁻¹ · Sₙ = a(rⁿ − 1)/(r − 1) · S∞ = a/(1 − r), only when −1 < r < 1
  • Quadratic pattern Tₙ = an² + bn + c: second difference = 2a · 3a + b = first difference between T₁ and T₂ · a + b + c = T₁
  • Term from the sum: Tₙ = Sₙ − Sₙ₋₁ (n ≥ 2) and T₁ = S₁
  • Sigma notation: number of terms = top − bottom + 1. Σ c = c × (number of terms)
  • Three terms in AP: 2b = a + c. Three terms in GP: b² = a·c
TYPE 1

Arithmetic sequence: find a, d, Tₙ, or which term

“The 5th term of an arithmetic sequence is 17 and the 9th term is 33. Determine the general term.” · “Which term of the sequence is equal to 301?”

  1. Write each given term with the formula: T₅ = a + 4d, T₉ = a + 8d.
  2. Subtract the two equations to find d. Then find a.
  3. For “which term”, set Tₙ equal to the value and solve for n. n must be a positive whole number.
Worked example
a + 4d = 17 …① a + 8d = 33 …② ②−①: 4d = 16 → d = 4, a = 1 Tₙ = 1 + (n − 1)(4) = 4n − 3 4n − 3 = 301 → n = 76 301 is the 76th term
TYPE 2

Arithmetic series: Sₙ and finding n

“How many terms must be added to give a sum of 210?” · “Calculate S₂₀.”

  1. Find a and d first.
  2. Choose the version of Sₙ that uses what you know (a and d, or a and last term).
  3. Finding n gives a quadratic. Reject the negative root.
Worked example

3 + 7 + 11 + … = 210. Find n.

a = 3, d = 4: Sₙ = n/2 [6 + 4(n − 1)] = n(2n + 1) 2n² + n − 210 = 0 → n = (−1 ± 41)/4 n = 10 (reject −10,5)
TYPE 3

Geometric sequence: find r, Tₙ, which term

“Which term of 2; 6; 18; … equals 1458?” · “The 2nd term is 6 and the 5th term is 162. Find r.”

  1. r = T₂ ÷ T₁. Given two terms: divide them (T₅/T₂ = r³).
  2. Solve the exponent equation by writing both sides with the same base. If you cannot, use logs.
Worked example
Tₙ = 2·3ⁿ⁻¹ = 1458 → 3ⁿ⁻¹ = 729 = 3⁶ n − 1 = 6, so n = 7 T₅/T₂ = 162/6 = 27 = r³ → r = 3
TYPE 4

Sum to infinity and convergence

“For which values of x will the series 5 + 5(x − 2) + 5(x − 2)² + … converge?” · “The sum to infinity is 24 and the first term is 8. Find r.” · “Calculate S∞.”

  1. Find r. Convergence means −1 < r < 1.
  2. Solve this double inequality for x. Do the same operation to all three parts.
  3. Then S∞ = a/(1 − r).
Worked example
r = x − 2: −1 < x − 2 < 1 → 1 < x < 3 8/(1 − r) = 24 → 1 − r = 1/3 r = 2/3
TYPE 5

Sigma notation

“Calculate Σ(3k − 2) from k = 1 to 20.” · “Write 2 + 6 + 18 + … + 4374 in sigma notation.” · “Determine Σ 2·3ᵏ⁻¹ from k = 1 to 8.”

  1. Write the first few terms by substituting k = 1, 2, 3.
  2. Decide arithmetic or geometric. Find a, d (or r) and the number of terms.
  3. Use the matching Sₙ formula.
  4. Writing a series in sigma notation: find Tₖ and the value of k at the last term.
Worked example
Σ(3k − 2), k = 1…20: 1 + 4 + 7 + … a = 1, d = 3, n = 20 S₂₀ = 10[2 + 19(3)] = 10(59) = 590 Σ 2·3ᵏ⁻¹, k = 1…8: a = 2, r = 3, n = 8 S₈ = 2(3⁸ − 1)/(3 − 1) = 6560
TYPE 6

Quadratic number patterns

“Determine the general term of 3; 8; 15; 24; …” · “Which term equals 399?” · “Show that the first differences form an arithmetic sequence.” · “Determine the 50th term.”

  1. Write the first differences, then the second difference. Constant second difference means quadratic.
  2. 2a = second difference. 3a + b = first of the first differences. a + b + c = T₁.
  3. Check by substituting n = 3 or 4.
Term381524
1st diff57, 9 …
2nd diff2 (constant), so a = 1
Worked example
3a + b = 5 → b = 2 a + b + c = 3 → c = 0 Tₙ = n² + 2n check T₄ = 16 + 8 = 24 ✓ n² + 2n = 399 → (n + 21)(n − 19) = 0 n = 19

Variation: they give the first differences as a linear pattern, or give the second difference and two terms. Same three equations, different givens.

TYPE 7

Tₙ from Sₙ

“The sum of the first n terms is Sₙ = 2n² + 3n. Determine T₁₀.” · “Show that the sequence is arithmetic.”

  1. Tₙ = Sₙ − Sₙ₋₁. Write Sₙ₋₁ by replacing every n with (n − 1). Brackets!
  2. Check T₁ = S₁ matches your formula.
Worked example
Sₙ₋₁ = 2(n − 1)² + 3(n − 1) = 2n² − n − 1 Tₙ = (2n² + 3n) − (2n² − n − 1) = 4n + 1 T₁ = 5 = S₁ ✓. Tₙ − Tₙ₋₁ = 4, so arithmetic. T₁₀ = 41
TYPE 8

Recurring decimals as a geometric series

“Write 0,7̇2̇ as a fraction using a geometric series.”

  1. Split into 0,72 + 0,0072 + 0,000072 + …
  2. a = 0,72 and r = 0,01.
  3. S∞ = a/(1 − r), then simplify.
Worked example
S∞ = 0,72 / (1 − 0,01) = 0,72 / 0,99 = 72/99 = 8/11
TYPE 9

Terms that are BOTH arithmetic and geometric

“Three numbers a, b, c are in arithmetic sequence with sum 15. If 1, 4 and 19 are added to them, the new numbers form a geometric sequence. Find the numbers.”

  1. AP: b is the middle term, so a + b + c = 15 gives b = 5, and a + c = 10.
  2. GP: new middle squared = product of the outer two.
  3. Substitute c = 10 − a, solve the quadratic, find both sets.
Worked example
New numbers: a + 1; 9; c + 19. (a + 1)(c + 19) = 81 with c = 10 − a: −a² + 28a + 29 = 81 → a² − 28a + 52 = 0 (a − 2)(a − 26) = 0 a = 2: numbers 2; 5; 8 → 3; 9; 27 (r = 3) a = 26: numbers 26; 5; −16 → 27; 9; 3 (r = ⅓)
TYPE 10

Word problems and “first term to exceed”

“She saves R200 in month 1 and R50 more each month than the previous month. How much in total after 24 months?” · “A ball is dropped from 10 m and rebounds to 60% of its previous height. How high after the 5th bounce?” · “After how many terms does the sequence first exceed 1000?”

  1. Test: constant difference (add the same) means arithmetic; constant ratio (multiply by the same) means geometric.
  2. Write a, d or r, n. Pick Tₙ (a single amount) or Sₙ (a total).
  3. “First exceeds”: set Tₙ > value, solve with logs. Dividing by log of a number less than 1 flips the inequality.
  4. Round n up to a whole number.
Worked example
Savings: a = 200, d = 50, n = 24 S₂₄ = 12[400 + 23(50)] = 12(1550) = R18 600 Ball: a = 10, r = 0,6; after 5th bounce = T₆ = 10(0,6)⁵ = 0,78 m 3·2ⁿ⁻¹ > 1000 → 2ⁿ⁻¹ > 333,3 → n − 1 > log₂333,3 = 8,38 n > 9,38, so n = 10 (T₁₀ = 1536)

Traps in this topic

  • Quoting S∞ when |r| ≥ 1. It does not exist.
  • n = 9,38 is not an answer. Terms are whole numbers.
  • Sigma count: k = 3 to 10 is 8 terms, not 7.
  • Using Sₙ when the question asks for one term, or the reverse.
  • Reading “after the 5th bounce” as T₅. The start height is T₁, so it is T₆.

Finance, Growth and Decay

Usually Question 4. Very predictable.
15 marks

Must know (all on the info sheet; know which one to pick)

  • Simple growth A = P(1 + in) · Simple decay A = P(1 − in)
  • Compound growth A = P(1 + i)ⁿ · Reducing balance A = P(1 − i)ⁿ
  • Future value of an annuity (savings): F = x[(1 + i)ⁿ − 1] / i
  • Present value of an annuity (loans): P = x[1 − (1 + i)⁻ⁿ] / i
  • Effective rate: 1 + ieff = (1 + i(m)/m)ᵐ
  • Match i and n to the same period. Monthly payments: i = rate ÷ 12 and n = months.
  • Payments are at the end of each period unless the question says the first payment is now.
  • You solve for P, F, x or n (never i in annuities). Solving for n uses logs.
TYPE 1

Simple vs compound interest and growth

“R20 000 is invested for 5 years at 8% p.a. Calculate the final amount if the interest is (a) simple (b) compounded annually.” · Also: inflation, population growth, appreciation.

  1. Percent to decimal: 8% is 0,08.
  2. Choose the formula, substitute, calculate.
  3. Inflation or appreciation is compound growth. Use A = P(1 + i)ⁿ.
Worked example
(a) A = 20 000(1 + 0,08 × 5) = R28 000 (b) A = 20 000(1,08)⁵ = R29 386,56
TYPE 2

Depreciation: straight-line and reducing balance

“A machine costing R250 000 depreciates at 15% p.a. on the reducing-balance method. (a) Value after 4 years? (b) After how many years is the value half of its cost?”

  1. Straight-line: A = P(1 − in). Reducing balance: A = P(1 − i)ⁿ.
  2. “How long”: write the equation, divide by P, take logs.
Worked example
(a) A = 250 000(0,85)⁴ = R130 501,56 (b) 125 000 = 250 000(0,85)ⁿ → 0,85ⁿ = 0,5 n = log 0,5 / log 0,85 = 4,27 years Straight-line for comparison: 250 000(1 − 0,15 × 4) = R100 000
TYPE 3

Nominal and effective interest rates

“Calculate the effective annual rate equivalent to 12% p.a. compounded monthly.” · “Find the nominal rate, compounded quarterly, that is equivalent to an effective rate of 10%.”

  1. m = periods per year (monthly 12, quarterly 4, half-yearly 2).
  2. Put the rate you know in the formula, solve for the other.
  3. Going backwards: take the m-th root of 1,1 (calculator: ^(1/4)).
Worked example
1 + ieff = (1 + 0,12/12)¹² = 1,126825… ieff = 12,68% (1 + i/4)⁴ = 1,10 → 1 + i/4 = 1,10^(1/4) = 1,024114… i = 4 × 0,024114 = 9,65% p.a. compounded quarterly
TYPE 4

Changing interest rates and timelines with deposits or withdrawals

“R20 000 earns 8% p.a. compounded quarterly for 2 years, then 9% p.a. compounded monthly for 3 years. Calculate the final amount.” · “R10 000 is invested at 8% p.a. compounded annually. After 2 years R3 000 is withdrawn. What is the balance after 5 years?”

  1. Draw a timeline. Mark every deposit, withdrawal and rate change.
  2. Grow the money one stretch at a time. Apply the deposit or withdrawal at its moment, then keep growing.
  3. Do not round between steps.
Worked example
After 2 years: 20 000(1 + 0,08/4)⁸ = R23 433,19 Final: 23 433,19 × (1 + 0,09/12)³⁶ = R30 665,73 Withdrawal: 10 000(1,08)² = 11 664 → minus 3 000 = 8 664 Balance: 8 664 × (1,08)³ = R10 914,14
TYPE 5

Future value annuity: savings and sinking funds

“R1 000 is deposited at the end of every month for 5 years at 9% p.a. compounded monthly. What is the final value?” · “How much must be saved monthly to have R150 000 in 4 years at 8% p.a. compounded monthly? (sinking fund)”

  1. i = rate/12, n = years × 12.
  2. Fv formula for the amount. To find x: rearrange x = F·i / [(1 + i)ⁿ − 1].
  3. Sinking fund = saving to replace an asset: same formula.
Worked example
i = 0,0075, n = 60: F = 1000[(1,0075)⁶⁰ − 1]/0,0075 = R75 424,14 i = 0,08/12, n = 48: x = 150 000(0,08/12)/[(1 + 0,08/12)⁴⁸ − 1] x = R2 661,94 per month

Deposits start now (first payment at time 0)? Add one extra period of interest: the answer is F × (1 + i), or use n + 1 payments and subtract one payment.

TYPE 6

Present value annuity: loan and bond repayments

“A loan of R800 000 is repaid over 20 years at 10,5% p.a. compounded monthly. Calculate the monthly instalment.” · “What is the present value of R2 500 per month for 3 years at 7,5%?”

  1. i = rate/12, n = months.
  2. Rearrange: x = P·i / [1 − (1 + i)⁻ⁿ].
  3. First payment one month after the loan is taken, unless told otherwise.
Worked example
i = 0,105/12, n = 240 x = 800 000(0,105/12) / [1 − (1 + 0,105/12)⁻²⁴⁰] x = R7 987,04 PV of R2 500 × 36 months at 7,5%: R80 369,78
TYPE 7

Outstanding balance after some payments

“Calculate the balance owing immediately after the 60th payment.”

  1. Method A (fastest): balance = present value of the payments still to come. Remaining n = total − paid.
  2. Method B: loan grown for k months minus the future value of the k payments made.
  3. Both give the same answer. Method A is one calculation.
Worked example (same loan as Type 6)
Remaining payments: 240 − 60 = 180 Balance = 7 987,04 × [1 − (1 + 0,105/12)⁻¹⁸⁰] / (0,105/12) = R722 548,12
TYPE 8

How long? (finding n with logs)

“How long will it take for R5 000 to grow to R8 000 at 7,5% p.a. compounded monthly?” · “How many payments of R9 000 will repay a R500 000 loan at 12% p.a. compounded monthly?”

  1. Substitute everything except n.
  2. Isolate (1 + i)ⁿ or (1 + i)⁻ⁿ.
  3. Take logs: n = log(value) / log(1 + i). Mind the negative exponent in PV.
  4. Convert months to years if the question asks for years. Round loan payments up.
Worked example
8 000 = 5 000(1 + 0,075/12)ⁿ → (1,00625)ⁿ = 1,6 n = log 1,6 / log 1,00625 = 75,4 months ≈ 6,29 years Loan: 500 000 = 9 000[1 − 1,01⁻ⁿ]/0,01 → 1,01⁻ⁿ = 1 − 0,5556 = 0,4444 n = −log 0,4444 / log 1,01 = 81,5 82 payments (the last one is smaller)
TYPE 9

Delayed start (first payment later) and payments at the start

“No repayments are made for the first 6 months…” · “The first deposit is made today.” · “The first repayment is made 4 months after the loan was granted.”

  1. Draw the timeline and mark where payment 1 falls.
  2. The PV formula values payments one period before the first payment. If payment 1 is at month 4, that is month 3.
  3. So grow the loan for (4 − 1) = 3 months first: new P = P(1 + i)³. Then use the normal formula with n = number of payments.
  4. Payment at the start of each period: treat it as one period earlier. Or add the payment made now separately.

Rule to repeat in the exam: PV formula sits one period before the first payment. FV formula sits at the last payment.

Traps in this topic

  • Using 9% instead of 0,0075 as i. Always divide by 12 for monthly.
  • n in years but i monthly. They must match.
  • Rounding i or the bracket early. Keep the full calculator value.
  • Forgetting the negative sign in (1 + i)⁻ⁿ.
  • Writing the answer without a Rand sign or with 3 decimals. Money is 2 decimals.

Functions and Graphs

Usually Questions 5, 6 and 7
35 marks

TYPE 1

Find the equation from a graph

“The sketch shows f(x) = a(x + 1)(x − 5)… Determine a.” · “Determine the equation of g if its asymptotes are x = −2 and y = 1 and it passes through (0; 3).” · “f(x) = a·bˣ passes through (0; 3) and (2; 12).”

  1. Pick the form that matches the information you can read: intercepts → factor form; turning point → vertex form; asymptotes → hyperbola/exponential form.
  2. Substitute a known point to find the last unknown.
  3. Check with a second point.
Worked examples
Parabola: intercepts −1 and 5, passes (0; −5) y = a(x + 1)(x − 5); −5 = a(1)(−5) → a = 1 y = x² − 4x − 5 Hyperbola: y = a/(x + 2) + 1, point (0; 3) 3 = a/2 + 1 → a = 4: y = 4/(x + 2) + 1 Exponential: a = 3 (x = 0); 3b² = 12 → b² = 4 b = 2 (b > 0), f(x) = 3·2ˣ
TYPE 2

Parabola: every feature they ask for

“Determine the coordinates of the turning point, the intercepts, the equation of the axis of symmetry, the range, and for which values of x is f(x) ≥ 0 / f increasing.”

  1. x-intercepts: f(x) = 0. y-intercept: x = 0.
  2. Turning point: x = −b/2a, then substitute for y. Or the midpoint of the two x-intercepts.
  3. Range: y ≥ q (smile) or y ≤ q (frown).
  4. Read increasing/decreasing and sign from the sketch.
Worked example: f(x) = x² − 4x − 5
(x − 5)(x + 1): x-intercepts (5; 0) and (−1; 0), y-intercept (0; −5) x = 4/2 = 2, f(2) = −9: turning point (2; −9) Axis: x = 2. Range: y ≥ −9. f(x) ≥ 0: x ≤ −1 or x ≥ 5. Increasing: x > 2.
TYPE 3

Hyperbola: asymptotes, intercepts, sketch

“Write down the equations of the asymptotes.” · “Determine the intercepts.” · “Determine the equation of the axis of symmetry with positive gradient.”

  1. Asymptotes: denominator zero gives x = p; the added constant gives y = q.
  2. y-intercept: x = 0. x-intercept: y = 0.
  3. Symmetry lines pass through (p; q) with gradient +1 and −1.
Worked example: g(x) = 2/(x − 1) + 3
Asymptotes: x = 1 and y = 3 y-intercept: 2/(−1) + 3 = 1 → (0; 1) x-intercept: 2/(x − 1) = −3 → x = 1/3 Symmetry lines: y = x + 2 and y = −x + 4
TYPE 4

Exponential and logarithm graphs

“The graph of g(x) = logbx passes through (9; 2). Determine b.” · “Write down the equation of the asymptote of f(x) = 2ˣ − 3.” · “Determine the range of f.”

  1. Log through a point: substitute, convert to exponential form (b² = 9, so b = 3).
  2. Exponential asymptote is the constant added: y = q. Range y > q (when a > 0).
  3. Reflection of bˣ in the y-axis is (1/b)ˣ = b⁻ˣ.
Worked example
logb9 = 2 → b² = 9 → b = 3 (b > 0) f(x) = 2ˣ − 3: asymptote y = −3, range y > −3, y-intercept (0; −2)
TYPE 5

Inverse functions

“Determine the equation of f⁻¹ in the form y = …” · “Sketch f and f⁻¹ on the same system.” · “Restrict the domain of f so that f⁻¹ is a function.” · “Write f⁻¹ in the form y = log…”

  1. Swap x and y. Make y the subject.
  2. Exponential becomes log: x = a·bʸ gives y = logb(x/a).
  3. Parabola: the inverse is not a function (fails the vertical line test). Restrict the parabola to x ≥ p (or x ≤ p).
  4. Sketch: reflect points in y = x. Intercepts swap, asymptotes swap.
Worked examples
f(x) = 3x − 6: x = 3y − 6 → f⁻¹(x) = (x + 6)/3 f(x) = 3·2ˣ: x = 3·2ʸ → 2ʸ = x/3 → y = log₂(x/3) f(x) = 2x²: x = 2y² → y = ±√(x/2) (not a function) Restrict x ≥ 0: f⁻¹(x) = √(x/2), domain x ≥ 0
TYPE 6

Transformations

“g(x) = f(x − 2) + 1. Describe the transformation.” · “Write down the equation of h if h is f reflected in the y-axis.” · “Write down the new asymptote.”

  1. Inside the bracket moves left/right, opposite to the sign: (x − 2) shifts right 2.
  2. Outside moves up/down with the sign.
  3. Move every key point (turning point, asymptote, intercept) with the same rule.
Worked example
f(x) = x² has turning point (0; 0) g(x) = (x − 2)² + 1: turning point (2; 1) f(x) = 2ˣ reflected in y-axis: h(x) = 2⁻ˣ = (½)ˣ y = 1/x shifted by f(x + 3) − 2: asymptotes x = −3 and y = −2
TYPE 7

Intersections and “for which x is f(x) > g(x)”

“Determine the coordinates of the points of intersection.” · “For which values of x is f(x) > g(x)?” · “For which values of x is f(x)·g(x) < 0?” · “For which x is f(x) ≤ 0?”

  1. Intersection: set f(x) = g(x), solve, then find y.
  2. f(x) > g(x): the x-values where the graph of f is above g. Read from the sketch between the intersection x-values.
  3. Product < 0: one graph above the x-axis, the other below.
  4. Always give x-intervals, not y-values.
TYPE 8

How many solutions? (f(x) = k)

“For which values of k does f(x) = k have two distinct real roots? / no real roots?”

  1. Draw the horizontal line y = k across the graph.
  2. Count where it cuts. Turning point height is the boundary.
Worked example: f(x) = x² − 4x − 5 (minimum −9)
k > −9: two distinct roots k = −9: one root (equal roots) k < −9: no real roots

Algebraic version: write x² − 4x − 5 − k = 0 and use Δ.

TYPE 9

Maximum vertical distance between two graphs

“PQ is a vertical line segment between the parabola and the line. Determine the maximum length of PQ.” · “Determine the value of x for which the distance is a minimum.”

  1. Length = (top graph) − (bottom graph) at the same x.
  2. This is a new function D(x), usually a parabola. Find its turning point: x = −b/2a, or D′(x) = 0.
  3. Check x lies between the intersection points.
Worked example: f(x) = x² − 4x − 5, g(x) = x − 1
Intersection: x² − 5x − 4 = 0, x ≈ −0,70 and 5,70 Between them g is on top: D = (x − 1) − (x² − 4x − 5) = −x² + 5x + 4 x = −5/(2·(−1)) = 2,5: D = −6,25 + 12,5 + 4 Maximum length = 10,25 units
TYPE 10

Sketching

“Sketch the graphs of f and g on the same system of axes. Show all intercepts, turning points and asymptotes.”

  1. Parabola: intercepts + turning point, smooth curve.
  2. Hyperbola: dashed asymptotes first, then two branches that approach but never touch them.
  3. Exponential: dashed asymptote, y-intercept, one more point.
  4. Label coordinates on the sketch. Marks go to labelled features.

Traps in this topic

  • (x − 2) moves the graph right 2, not left.
  • Asymptotes written as numbers. Write the equation: y = 3.
  • Giving a range as x-values, or a domain as y-values.
  • Hyperbola “x-intercept”: set the whole function to zero and solve. Don’t set the denominator to zero.
  • Sketch with no labels. You lose the sketch marks even if the shape is right.

Differential Calculus

Usually Questions 8, 9, 10 and sometimes 11
35 marks

Must know

  • First principles: f′(x) = limh→0 [f(x + h) − f(x)] / h
  • Power rule: d/dx (xⁿ) = n·xⁿ⁻¹. Constant → 0. Notation: f′(x), dy/dx, Dx.
  • Rewrite first: √x = x^(1/2) · 1/x² = x⁻² · 3/√x = 3x^(−1/2) · expand brackets · simplify fractions.
  • Tangent: gradient m = f′(a), then y − y₁ = m(x − x₁). Horizontal tangent: f′ = 0. Parallel lines: same m. Perpendicular: m₁·m₂ = −1.
  • Turning points: f′(x) = 0. Increasing: f′ > 0. Decreasing: f′ < 0.
  • Concavity: f″ > 0 concave up, f″ < 0 concave down. Inflection point: f″ = 0 with a change of concavity.
  • Right-prism formulas must be known: cuboid V = lbh · cylinder V = πr²h, S = 2πr² + 2πrh. Cones/spheres are given in the question.
TYPE 1

Differentiate from first principles

“Determine f′(x) from first principles if f(x) = 3x² − 2x.” · “… if f(x) = 2/x.”

  1. Write the definition. Calculate f(x + h) in brackets.
  2. Subtract f(x). Everything without h cancels. Factor h and cancel it.
  3. Only then take the limit. Keep writing limh→0 until you cancel h.
Worked examples
f(x + h) − f(x) = 3(x + h)² − 2(x + h) − 3x² + 2x = 6xh + 3h² − 2h = h(6x + 3h − 2) f′(x) = lim (6x + 3h − 2) = 6x − 2 f(x) = 2/x: [2/(x + h) − 2/x]/h = [2x − 2(x + h)] / [x(x + h)h] = −2h / [x(x + h)h] = −2/[x(x + h)] f′(x) = −2/x²
TYPE 2

Differentiate using the rules

“Determine f′(x) if f(x) = 2x³ − 5x + 4/x² − √x.” · “Determine Dx[(2x − 1)²].” · “Determine dy/dx if y = (x² − 9)/(x − 3).”

  1. Rewrite every term as a power of x. Expand or simplify first.
  2. Differentiate term by term.
  3. If asked, write the answer back with positive exponents.
Worked examples
f(x) = 2x³ − 5x + 4x⁻² − x^(1/2) f′(x) = 6x² − 5 − 8x⁻³ − ½x^(−1/2) (2x − 1)² = 4x² − 4x + 1 → 8x − 4 y = (x − 3)(x + 3)/(x − 3) = x + 3 → dy/dx = 1
TYPE 3

Equation of a tangent

“Determine the equation of the tangent to f at x = 3.” · “Determine the equation of the tangent to f that is parallel to y = −2x + 1.” · “Determine the point where the tangent is horizontal.”

  1. Point: if you are given x, find y from f(x).
  2. Gradient: f′ at that x. If given a parallel line, solve f′(x) = its gradient to find x.
  3. Use y − y₁ = m(x − x₁). Simplify to y = mx + c.
Worked example: f(x) = x² − 4x − 5
f′(x) = 2x − 4. At x = 3: m = 2, f(3) = −8 y + 8 = 2(x − 3) → y = 2x − 14 Parallel to y = −2x + 1: 2x − 4 = −2 → x = 1, f(1) = −8 y + 8 = −2(x − 1) → y = −2x − 6
TYPE 4

The cubic graph question (the big one)

“Given f(x) = x³ − 3x² − 9x + 27. (a) Show that (x − 3) is a factor. (b) Determine the x-intercepts. (c) Determine the coordinates of the turning points. (d) Sketch f. (e) Determine the x-coordinate of the point of inflection. (f) For which x is f concave up / f decreasing? (g) For which k does f(x) = k have three distinct real roots?”

  1. Factor theorem: f(3) = 0 means (x − 3) is a factor. Divide to get the quadratic, factorise fully.
  2. x-intercepts: factors = 0. y-intercept: f(0).
  3. Turning points: f′(x) = 0, then f(x) for each y.
  4. Inflection: f″(x) = 0.
  5. Sketch with all of these labelled. Cubic with positive x³ coefficient rises on the right.
Worked example
f(3) = 27 − 27 − 27 + 27 = 0 ✓ f(x) = (x − 3)(x² − 9) = (x − 3)²(x + 3) x-intercepts: (−3; 0) and (3; 0). y-intercept (0; 27) f′(x) = 3x² − 6x − 9 = 3(x − 3)(x + 1) x = −1: f = 32 → (−1; 32) local max x = 3: f = 0 → (3; 0) local min (touches the x-axis) f″(x) = 6x − 6 = 0 → x = 1, f(1) = 16 → inflection (1; 16) Concave up: x > 1. Decreasing: −1 < x < 3. Three distinct roots of f(x) = k: 0 < k < 32

The root at x = 3 is a double root, which is why the graph touches the axis there. Two equal roots at a turning point is a classic they test.

TYPE 5

Find a, b, c, d from given information

“f(x) = x³ + ax² + bx has turning points at x = 1 and x = 3. Determine a and b.” · “The graph has a turning point at (2; −6) and passes through (0; 4).”

  1. Turning point at x = t: f′(t) = 0. A point (t; y): f(t) = y.
  2. Each fact gives one equation. Solve the system.
  3. Or use the roots of f′: sum of roots = −B/A, product = C/A.
Worked example
f′(x) = 3x² + 2ax + b = 0 has roots 1 and 3 Sum: −2a/3 = 4 → a = −6. Product: b/3 = 3 → b = 9 f(x) = x³ − 6x² + 9x: f(1) = 4, f(3) = 0 ✓
TYPE 6

Read a graph of f′ (the derivative)

“The sketch shows the graph of f′(x), a parabola with x-intercepts −1 and 3. (a) For which x is f increasing? (b) At which x does f have a local maximum? (c) At which x is f concave down? (d) Determine f′(0).”

TYPE 7

Optimisation (maximum / minimum problems)

“An open box with a square base has a total surface area of 48 m². Show that V = 12x − ¼x³. Determine x for the maximum volume.” · “A farmer has 100 m of fencing for a rectangular camp against a wall…” · “A cylindrical can has volume … minimise the surface area.”

  1. Draw and define the variables.
  2. Constraint equation (given total area, perimeter, volume).
  3. Make the thing to optimise a function of one variable.
  4. Differentiate, set equal to 0, solve.
  5. Confirm max or min (second derivative or sign change). Reject answers outside the allowed values.
  6. Answer the question asked, with units.
Worked examples

Open box, base x by x, height h. Surface area 48.

x² + 4xh = 48 → h = (48 − x²)/(4x) V = x²h = x(48 − x²)/4 = 12x − ¼x³ V′ = 12 − ¾x² = 0 → x² = 16 → x = 4 V″ = −1,5x < 0, so a maximum. h = 32/16 = 2 x = 4 m, h = 2 m, V = 32 m³

100 m fence, 3 sides, width x: length = 100 − 2x

A = x(100 − 2x) = 100x − 2x² → A′ = 100 − 4x = 0 x = 25 m, length 50 m, A = 1 250 m²
TYPE 8

Rates of change: average, instantaneous, motion

“A ball’s height is h(t) = −5t² + 20t. (a) Velocity after 1 s? (b) When is the velocity zero? (c) Maximum height? (d) When does it hit the ground? (e) Average velocity between t = 1 and t = 3?” · “At what rate is the volume changing with respect to the radius when r = 2?”

  1. Average rate of change = gradient between two points: [f(b) − f(a)] / (b − a). No calculus.
  2. Instantaneous rate = derivative. Velocity = h′(t), acceleration = h″(t).
  3. Maximum height: velocity = 0, then put that t into h(t).
  4. Hits the ground: h(t) = 0.
  5. Negative velocity means moving downward.
Worked example
v(t) = h′(t) = −10t + 20. v(1) = 10 m/s v = 0: t = 2 s. h(2) = −20 + 40 = 20 m (max height) h = 0: −5t(t − 4) = 0 → t = 4 s Average velocity (1 to 3): [h(3) − h(1)] / 2 = (15 − 15)/2 = 0 m/s v(4) = −20 m/s (20 m/s downward)
TYPE 9

Concavity and points of inflection (interpretation questions)

“For which values of x is f concave up?” · “Where is the gradient of the tangent a minimum?” · “Show that f has no stationary points.”

  1. Concave up: f″(x) > 0. Concave down: f″(x) < 0.
  2. The gradient of the tangent is smallest (or largest) at the inflection point, where f″ = 0.
  3. No turning points: show f′(x) = 0 has Δ < 0.
Example: f(x) = x³ + 3x + 1
f′(x) = 3x² + 3 = 0 → x² = −1: no real solution So there are no turning points (f′ is always positive: f always increasing).
TYPE 10

Transformed cubic and “equal roots” conditions

“g(x) = f(x − 2) + 3. Determine the turning points of g.” · “For which values of k will f(x) = k have exactly one real root?” · “For which values of x is f′(x)·f″(x) < 0?”

  1. Shift every key point: (x; y) of f moves to (x + 2; y + 3) for g(x) = f(x − 2) + 3.
  2. One real root: line y = k above the local maximum or below the local minimum.
  3. Product of f′ and f″: find where each is positive/negative, then use a sign table.
Using the cubic from Type 4
g(x) = f(x − 2) + 3: turning points (1; 35) and (5; 3) f(x) = k exactly one real root: k > 32 or k < 0 (k = 0 or 32 gives two roots, one of them a double root)

Traps in this topic

  • Differentiating before rewriting (4/x² must become 4x⁻²).
  • Giving only x at a turning point. They want (x; y) when they ask for coordinates.
  • Skipping h cancel in first principles, or dropping “lim” early.
  • Optimisation with two variables in V. Eliminate one first.
  • Not stating max or min justification.
  • Mixing up f′ = 0 (turning points) with f″ = 0 (inflection).

Counting Principle and Probability

Usually Questions 11 and 12
15 marks

Must know

  • P(A or B) = P(A) + P(B) − P(A and B)
  • Mutually exclusive: P(A and B) = 0 · Complementary: P(not A) = 1 − P(A)
  • Independent: P(A and B) = P(A) × P(B). This is also your test for independence.
  • Probability = favourable outcomes ÷ total outcomes. Always between 0 and 1.
  • Fundamental counting principle: multiply the choices for each position.
  • n different objects in a row: n! · With repeats: n! / (a! · b!)
  • Dependent events (no replacement): the second probability changes.
TYPE 1

Venn diagrams and the addition rule

“P(A) = 0,4; P(B) = 0,5; P(A or B) = 0,7. Calculate P(A and B).” · “40 learners: 22 take Maths, 18 take Science, 8 take both…”

  1. Start the Venn with the overlap (both). Then each “only”, then “neither”.
  2. Everything adds to the total (1 or the number of learners).
  3. Use algebra (x for the overlap) when the numbers are not given directly.
Worked examples
0,7 = 0,4 + 0,5 − P(A and B) → P(A and B) = 0,2 Maths only 22 − 8 = 14; Science only 18 − 8 = 10; both 8 Neither = 40 − (14 + 10 + 8) = 8 → P(neither) = 0,2
TYPE 2

Are A and B independent / mutually exclusive?

“Show, with calculations, that A and B are independent.” · “Are the events mutually exclusive? Motivate.” · “Determine x if the events are independent.”

  1. Independent: compute P(A) × P(B) and compare with P(A and B). Equal means independent. Write the conclusion in words.
  2. Mutually exclusive: P(A and B) = 0? If it is not 0, they are not.
  3. Find an unknown: put the rule into an equation and solve.
Worked examples
P(A) = 0,4, P(B) = 0,5, P(A and B) = 0,2: 0,4 × 0,5 = 0,2 ✓ independent P(A and B) = 0,2 ≠ 0: not mutually exclusive Classes: P(M) × P(S) = 0,55 × 0,45 = 0,2475 ≠ 0,2: not independent Independent, P(A) = 0,3, P(A or B) = 0,65, P(B) = x: 0,3 + x − 0,3x = 0,65 → 0,7x = 0,35 x = 0,5 Mutually exclusive, P(A) = 0,3, P(B) = 2x, P(A or B) = 0,7: 0,3 + 2x = 0,7 → x = 0,2
TYPE 3

Worked example
P(girl and soccer) = 15/100 = 0,15 P(girl) × P(soccer) = 0,6 × 0,39 = 0,234 ≠ 0,15 Not independent
TYPE 4

Tree diagrams (with and without replacement)

“A bag has 5 red and 3 blue balls. Two balls are drawn without replacement. Draw a tree diagram. Calculate P(both red), P(different colours), P(at least one blue).”

  1. Draw the branches. Write the probability on each branch.
  2. Without replacement: numerator AND denominator change on the second draw.
  3. Multiply along a path (AND). Add paths (OR).
  4. “At least one”: 1 − P(none).
  5. Check all end-point probabilities add to 1.
Worked example
RR: 5/8 × 4/7 = 20/56 = 5/14 RB: 5/8 × 3/7 = 15/56 BR: 3/8 × 5/7 = 15/56 BB: 3/8 × 2/7 = 6/56 Different colours: 15/56 + 15/56 = 30/56 = 15/28 At least one blue: 1 − 20/56 = 36/56 = 9/14 Check: 20 + 15 + 15 + 6 = 56 ✓
TYPE 5

Counting principle: codes, numbers, number plates

“How many 4-digit codes can be formed from 0–9 (a) with repetition (b) without repetition? (c) How many 4-digit numbers are even, no repetition, and do not start with 0?” · “A number plate has 3 letters, then 3 digits, then GP.”

  1. Draw a box for each position. Write the number of choices in each box.
  2. Fill the restricted positions first (first digit not 0; last digit even).
  3. Multiply the boxes. If one restriction splits into cases, calculate each case and add.
  4. Check: total minus the opposite case.
Worked example
(a) 10 × 10 × 10 × 10 = 10 000 (b) 10 × 9 × 8 × 7 = 5 040 (c) Last digit 0: 9 × 8 × 7 = 504 Last digit 2, 4, 6 or 8: 4 × (8 first, since not 0 and not used) × 8 × 7 = 1 792 Even numbers: 504 + 1 792 = 2 296 Check: all 4-digit, no repeat = 9 × 9 × 8 × 7 = 4 536; odd = 5 × 8 × 8 × 7 = 2 240; 4 536 − 2 240 = 2 296 ✓ Number plate: 26³ × 10³ (×1 for GP) = 17 576 000
TYPE 6

Arrangements of letters and people

“How many different arrangements of the letters of SCIENCE are possible? (a) in total (b) if S is the first letter (c) if the vowels must be together.” · “Six friends sit in a row. Two refuse to be apart / refuse to sit together.”

  1. All different: n!. Repeated letters: divide by the factorial of each repeat. (The question will say if identical letters are treated as the same.)
  2. Fixed positions: remove those letters from the count.
  3. “Must be together”: glue them into one block. Arrange the blocks, then arrange inside the block.
  4. “Not together” = total − together.
Worked example
SCIENCE: 7 letters, C twice, E twice (a) 7!/(2! 2!) = 5040/4 = 1 260 (b) S first: remaining 6 letters, 6!/(2! 2!) = 180 Six friends, two together: block of 2 + 4 others = 5 items: 5! × 2! = 240 Not together: 6! − 240 = 720 − 240 = 480
TYPE 7

Probability using counting

“A 4-digit PIN is chosen at random, digits can repeat. What is the probability all 4 digits are different? / at least two are the same?” · “What is the probability that a random arrangement of SCIENCE starts with S?”

  1. Total outcomes using the counting principle.
  2. Favourable outcomes using the counting principle.
  3. P = favourable / total. “At least” = 1 − P(opposite).
Worked example
All different: 5 040 / 10 000 = 0,504 At least two the same: 1 − 0,504 = 0,496 SCIENCE starts with S: 180 / 1 260 = 1/7

Traps in this topic

  • Using the same denominator on the second draw when there is no replacement.
  • Saying “independent” without showing P(A) × P(B) = P(A and B).
  • Adding along a branch or multiplying across different branches. AND is multiply along, OR is add across.
  • Forgetting the leading-zero restriction in digit problems.
  • A probability above 1, or negative. That is always wrong.

First 5 minutes of the paper

  1. Read the whole paper. Mark the parts you can do immediately.
  2. Do those first, then return. Easy marks are never wasted.
  3. Write the info-sheet formulas you tend to forget in the margin of your rough work.

Last 10 minutes

  • Check each answer for sense: probabilities between 0 and 1, lengths positive, money to 2 decimals.
  • Substitute solutions back (surds, logs, simultaneous equations).
  • Have a unit, a conclusion or a labelled sketch on every context question.

Bring

  • Scientific calculator with fresh batteries, pen, pencil, ruler, ID or admission letter, a water bottle if allowed.

If you freeze

  • Move on. Come back with a clear head.
  • Write down anything you know about the question: a formula, a given, a sketch. That is where method marks come from.
